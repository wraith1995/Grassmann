Grassmann matrix calculus

Declare your spaces, functions and variables — then take the coordinate-free derivative.

Examples

Dimensions

Declare dimension variables (bound to a size), then use them in spaces and variable types — e.g. R^n, vector(n), matrix(m,n), V = R^n.

Spaces

Functions

A parameterization defines an immersion ℝᵏ→ℝⁿ from its params/components (leave dom/cod blank). An opaque function is a black box with optional numeric components.

Bases

e.g. ImageBasis(phi), OrthonormalBasis(b), DualBasis(b) — validated against your declarations on Compute.

Variables

Free variables of the expression are detected automatically; set each type. Type any space expression (e.g. R^n, R^m -> R^n, (R^3)* (x) R^3) or pick a suggestion.
Every input is realized in a basis — default is the standard (Euclidean) basis; pick a declared basis to change it.
