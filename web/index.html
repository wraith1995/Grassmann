Grassmann matrix calculus

Type a matrixcalculus-style expression — get the coordinate-free derivative.
Parameterizations (optional) — manifolds φ: ℝᵏ → ℝⁿ for tangent-space variables
A variable can then be typed tangent(name) / normal(name) / cotangent(name) / conormal(name); differentiating w.r.t. the parameterization name gives the covariant derivative.
