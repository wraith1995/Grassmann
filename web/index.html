Grassmann matrix calculus

Declare your spaces, functions and variables — then take the coordinate-free derivative.

Examples

Dimensions

Symbolic dimension variables — use them in spaces and variable types, e.g. R^n, R^m -> R^n, V = R^n. For a specific size, just write the literal (R^3) in the type — symbolic dims default to a size when you Generate Python.

Spaces

Functions

A parameterization defines an immersion ℝᵏ→ℝⁿ from its params/components (leave dom/cod blank). An opaque function is a black box with optional numeric components.

Bases

e.g. ImageBasis(phi), OrthonormalBasis(b), DualBasis(b) — validated against your declarations on Compute.

Variables

Free variables of the expression are detected automatically; set each type from the dropdown (built from your declarations), or choose custom… to type any space expression (e.g. R^m -> R^n, (R^3)* (x) R^3).
Every input is realized in a basis — the default is rendered literally from its space: {e₁,e₂,e₃}, a dual basis {e¹,e²,e³}, a tensor basis {e₁,e₂} ⊗ {f₁,f₂}; pick a declared basis to change it.
